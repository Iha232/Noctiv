    Document Viewer Settings

    PDF Viewer

    ⚠ Chrome PDF Viewer Limitation: Chrome's built-in PDF viewer runs in an isolated sandboxed context that extension content scripts cannot access directly. Noctiv applies a CSS brightness/inversion filter to the PDF embed element, which makes white backgrounds appear dark and keeps text readable. Coloured images and diagrams will have slightly shifted hues — this is a known limitation with no workaround from an extension content script. For PDF.js-based viewers (e.g. on websites that embed their own PDF reader), full DOM theming is applied instead.

    PPT/Slides Viewer

    ⚠ Canvas Slide Limitation: Google Slides and Office Online render presentation slides as HTML5 <canvas> elements. CSS cannot change canvas pixel content. Noctiv themes all surrounding chrome (toolbars, menus, filmstrip, sidebar, speaker notes) and applies a CSS inversion filter to the canvas element itself to approximate a dark slide surface. Individual text colours, fills, and image hues inside the slide may appear shifted. The original presentation file is never modified.

    Platform Support Details

    • ✓ Chrome PDF Viewer — filter-based dark mode on embed surface (*.pdf URLs)
    • ✓ PDF.js viewers — full DOM theming (toolbar, sidebar, page wrappers)

    • ✓ Microsoft Office Online (office.live.com) — chrome theming + canvas filter
    • ✓ OneDrive (onedrive.live.com) — chrome theming + canvas filter
    • ✓ SharePoint (*.sharepoint.com) — chrome theming + canvas filter
    • ✗ cross-origin iframes — not accessible per browser security policy
